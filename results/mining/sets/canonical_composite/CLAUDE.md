# canonical_composite — rank-product compositions (code arg `"canonical_composite"`)

Compositions of the canonical individual factors — demeaned-rank pair
products `(CsRank(A)-0.5)·(CsRank(B)-0.5)` and 3-way products.
Names use the `cxalpha_` prefix (distinct from canonical's `calpha_`).

**Reset 2026-07-10.** The original 26-factor set (composed from the
79-parent pool of canonical rounds 7–9) was wiped; this fresh campaign
recomposes over the **current 105 individual canonical factors**,
including classes the old compositions never saw (day-types, pins, true
gaps, at-extreme textures). Old set is in git history.

## Current state
- 24 factors after fresh Round 1 (18/18 prior-winner re-derivations
  replicated + 6 new-parent compositions; best: aggression-at-highs ×
  stretch × clock, OOS 0.053). Diversity 0.806.

## Composition laws (experience_memory.json)
- Pairs: excitement-COUNT parent × stretch/STATE parent → **negative**
  sign (agreement is bearish).
- 3-way products → **positive** sign, richest tier; volclock works only
  inside 3-ways.
- Parents below ~0.05 IS IC don't compose; count×count fails OOS.
- S2 correlation is checked vs THIS set's residents (compositions are
  near-orthogonal to parents by construction).
